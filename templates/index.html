Scenario 1
Working Computer Lab

Demonstrates a healthy star topology: Gateway router, central switch, two student desktops, instructor laptop, and network printer. All IP configurations are valid and communication succeeds.

Key Concept: L2 switching, default gateway routing, ICMP Ping verification.
Scenario 2
Duplicate IP Conflict

Two workstations are inadvertently assigned the same static IP address (192.168.10.50). Observe the real-time collision alert, ambiguous ARP state, and use Guided Resolution to fix it.

Key Concept: IPv4 address collisions, ARP poisoning hazards, automated candidate IP discovery.
Scenario 3
DHCP Dynamic Leases

Wireless Access Point network where student smartphones and laptops dynamically request IP leases from the gateway's DHCP pool. Demonstrates lease allocation, renewal, and pool tracking.

Key Concept: DORA workflow, address lease pool exhaustion, dynamic host configuration.
Scenario 4
Disconnected Device Diagnostic

A workstation is disconnected from the departmental switch. A simulated ping fails with topological diagnostics. Reconnect the link to witness instant recovery.

Key Concept: Layer 1/2 physical link diagnostics, graph traversal, reachability validation.

Unapproved Rogue Device

An unauthorized personal laptop joins the office LAN. The simulator flags it as unapproved and generates security alerts for administrator review and manual approval.

Key Concept: Network access triage, approved device registry, rogue host detection.
Computer Networks Academic Reference Guide

Fundamental networking concepts modelled deterministically inside the NodeScope simulation engine.

IPv4 & Subnetting

CIDR notation (e.g. /24) establishes network boundaries and host capacities. Broadcast and network IDs cannot be assigned to hosts. NodeScope validates all host assignments against the defined subnet mask.

DHCP Allocation

Dynamic Host Configuration Protocol leases IP addresses from a pre-defined address pool. The simulator tracks active leases and prevents assignment of addresses occupied by static hosts or the gateway.

IP Address Conflicts

Occurs when two active interfaces share an identical IPv4 address on the same broadcast domain. NodeScope detects duplicate assignments, flags ambiguous ARP entries, and recommends free alternative IPs.

ARP (Address Resolution)

Translates Layer 3 IP addresses into Layer 2 physical MAC addresses. NodeScope provides an interactive Virtual ARP table indicating normal resolution versus collision ambiguity.

ICMP Echo (Ping)

Tests end-to-end reachability. Evaluates power status, IP validity, same-subnet local traversal (where gateway is not required), and BFS topological path continuity through intermediate switches.

Device Registry & Triage

Models network security policy. New end devices are flagged as Unapproved until authorized by an administrator, preventing unmonitored rogue attachments on the LAN.
